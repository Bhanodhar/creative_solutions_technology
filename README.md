# Creative Solution Technology — React Website Redesign

Modern, SEO-ready, multi-page React + Vite web application built with a **Crisp Daylight Corporate** palette (`#F8FAFC` canvas, `#FFFFFF` elevated surfaces, `#0F172A` / `#1E3A8A` navy, `#2563EB` cobalt, and `#0891B2` cyan).

## Features
- **All 6 Pages Included with Exact Content:** Home (`/`), About (`/about`), Services (`/services`), Careers (`/careers`), Clients (`/clients`), and Contact (`/contact`).
- **Upgraded Visuals:** Replaces dated clip-art and low-res graphics with a custom SVG vector brand mark, an architectural hero UI showcase, clean Lucide iconography, and vector client monograms.
- **Fast Production Load:** Route-level code splitting (`React.lazy` + `Suspense`), manual vendor chunk splitting in `vite.config.js`, and lightweight Framer Motion transitions.
- **SEO Ready:** Per-page `<title>`, `<meta name="description">`, canonical URLs, JSON-LD `Organization` schema, `robots.txt`, and `sitemap.xml`.

## Local Setup & Run Instructions
1. Extract the zip folder and open it in your terminal:
   ```bash
   cd creative-solution-tech
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```
4. Build and preview production bundle:
   ```bash
   npm run build
   npm run preview
   ```
